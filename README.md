# Syscall Explorer

在 Linux 本机通过 strace 启动目标程序，跟踪它及子进程的系统调用。在浏览器中按累计次数绘制 treemap，每 0.5 秒更新一次。每次调用在进入时计数，包括返回错误的调用。

需要 Python 3.8+ 和 strace，运行环境须允许 ptrace。

```sh
python3 explorer.py -- ls -la /tmp
```

打开 http://127.0.0.1:8765 。短命令结束后仍可查看最终统计。省略命令可运行持续扫描目录的内置示例。使用 --port 选择端口，例如 `python3 explorer.py --port 9000 -- sleep 10`。

按 Ctrl+C 关闭服务，并结束仍在采集进程组内运行的程序。目标程序的输出保留在终端。strace 会影响程序执行速度。

### 从浏览器切换目标

1. 点击「结束目标程序」停止当前示例或由本工具启动的程序。已自然退出的目标可直接切换。
2. 「启动程序」支持浏览采集主机上的可执行文件，也可输入路径或 PATH 中的命令名。参数单独填写，含空格的参数可用引号包住。
3. 要观察正在运行的程序，选择「附加进程」，从本机进程列表中选中目标并点击「附加并采集」。可按名称筛选，用列表中的 PID 区分同名进程，点击「刷新列表」查看新启动的程序。每次成功开始新的会话都会重新计数。点击「分离进程」可结束跟踪，目标继续运行。

附加需要当前用户具有目标进程的 ptrace 权限。Linux 的 Yama、容器策略或进程属主可能限制附加；页面显示 strace 返回的诊断信息。
